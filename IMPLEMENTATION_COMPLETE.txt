WORKFLOW STEPS:

  2. Droplet initialization (setFields)
  3. Fluid solver execution (incompressibleVoF)
  4. FSI coupling orchestration (pressure → deformation)
  5. Python validation (comparison plots)

COMMAND-LINE OPTIONS:
  --nprocs N        : Number of CPU cores
  --no-mesh         : Skip mesh generation
  --no-fluid        : Skip fluid solver
  --no-solid        : Skip FSI coupling
  --iterative       : Use iterative coupling
  --validate        : Validation only

RUNTIME ESTIMATES:
  Single CPU:  ~70 minutes (mesh + fluid + coupling + validation)
  4 CPUs:      ~20 minutes (3.5× speedup)
  8 CPUs:      ~12 minutes (5.8× speedup)
